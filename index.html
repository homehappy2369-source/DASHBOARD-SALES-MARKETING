Pengaturan

Konfigurasi koneksi database dan pengelolaan data.

Koneksi Supabase

Isi kredensial proyek baru milik Happy Home.

Belum terhubung
Jangan masukkan service_role key di aplikasi browser. Gunakan Project URL dan publishable/anon key saja, lalu aktifkan RLS pada seluruh tabel.

Konfigurasi disimpan di browser ini. Untuk deploy, isi nilai yang sama pada app.js atau konfigurasi environment saat proses build. Data baru benar-benar online setelah tabel dan kebijakan RLS disiapkan.

Keamanan akun

Ubah kata sandi akun yang sedang login.

Fitur ini memerlukan login Supabase yang aktif. Mode demo tidak memiliki akun atau kata sandi sungguhan.

Data demo

Data contoh untuk menguji fitur sebelum memakai data asli.

Kamu dapat memuat ulang data contoh atau menghapus data lokal. Ini tidak menghapus data di Supabase.

Login online menggunakan Supabase Auth. Buat satu akun kepala divisi dari Supabase Dashboard, lalu nonaktifkan pendaftaran publik agar orang lain tidak bisa membuat akun sendiri.

Checklist aktivasi online

Langkah yang harus dilakukan sebelum dipakai untuk data kerja.

  1. Buat proyek Supabase baru khusus Dashboard Sales & Marketing.
  2. Buat satu pengguna kepala divisi melalui Authentication → Users.
  3. Buat tabel omzet, chat, dan BCG serta aktifkan Row Level Security.
  4. Terapkan kebijakan agar hanya user yang diizinkan dapat membaca dan mengubah data.
  5. Hubungkan proyek di menu ini, lalu uji login dan sinkronisasi dari perangkat lain.

Versi awal ini menyiapkan antarmuka dan mode demo. Sinkronisasi CRUD Supabase untuk seluruh modul dan kebijakan SQL perlu diaktifkan setelah proyek dibuat agar tidak berpura-pura menyimpan data online.
